# 内联工作卡与 Pele Studio 使用指南

`antigravity-pele` 针对 Antigravity 中三种不同的内容载体采用了**按场景最优路由**策略，既保证聊天里的交互体验，又兼顾工程文档在 GitHub / GitLab / Obsidian 中的通用可读性。

---

## 1. 三端渲染路由策略

| 内容表面 | 渲染形式 | 为什么这样设计 |
| :--- | :--- | :--- |
| **Chat 对话气泡** | 交互式 HTML 内联工作卡（`<agent-embed>`） | 支持缩放、看源码、切分栏、自适应竖版高度、一键导出高清图 |
| **会话 `.md` Artifact** | 亮暗自适应静态 `.svg` 图片（`![Title](/abs/path.svg)`） | Antigravity 会话文档视图可直接无损渲染本地 SVG，且自动匹配浅色/暗黑模式 |
| **项目仓库 `.md` 文件** | 标准 ```` ```mermaid ```` 围栏代码块 | 保持对 GitHub、GitLab、Obsidian、VS Code 等外部平台的 100% 原生兼容性 |

---

## 2. 对话内联工作卡（Flexoki Card）

每当助手通过 `pele_render_card` 生成图表时，对话中会展示一张采用 **Flexoki** 暖墨色板的工作卡。

### 吸顶常驻工具栏

无论图表高度如何或如何缩放，顶部 40px 工具栏始终**吸顶常驻**，包含以下控件：

1. **图表标题与类型徽章**：显示图表名称及检测到的图表类型（如 `FLOWCHART`、`SWIMLANE`、`GANTT`）。
2. **三模式视图切换**：
   - **视图**：纯画布查看图表。
   - **源码**：查看原始 Mermaid / Pele 源码（带主题高亮底色）。
   - **分栏**：左侧实时画布 + 右侧只读源码对照查看。
3. **双风格配色实时切换器**：
   - 默认暖墨（Flexoki）：**默认暖墨 (自动)**、`flexoki-light`（浅色）、`flexoki-dark`（深色）。
   - 政务清爽（Gov）：**政务清爽 (浅色)**（纯白底 + 政务蓝/青绿高对比爽洁配色，适合政务汇报、公文与流程审计）、**政务清爽 (自动)**、`gov-dark`（深蓝夜色模式）。
   - 跟随宿主（Host）：继承当前页面 CSS 变量。
   - 在卡片工具栏或 Pele Studio 右上角选择后，画面立即无闪烁切换，随后点击 **SVG** / **PNG** 导出也会直接采用切换后的新配色。
4. **缩放与拖拽控制**：
   - `-` / 当前百分比按钮（点击即重置为 `自适应画布大小 Fit`） / `+`（缩放范围 `20%` 至 `400%`）。
   - 鼠标在画布上**按住左键拖拽**可平移画布。
   - **不劫持普通滚轮**：直接滚动鼠标滚轮会自然滚动外层页面；按住 **`Ctrl + 滚轮`**（macOS 为 `Cmd + 滚轮`）才执行缩放。
5. **`自适应` 高度与 `全屏` / 全高卡片视图**：
   - 内联卡片与独立 HTML 卡片默认启用 **`height: "auto"` 自适应高度**。
   - 当渲染**竖版流程图（`flowchart TD`）、时序图、类图或高层树状图**时，卡片会根据容器宽度等比例计算自然所需高度（内联模式上限默认 `1400px`，独立 HTML 页默认 `2400px`），避免传统 416px 固定窗口把竖图缩成过小的缩略图。
   - 点击工具栏的 **`自适应`** 按钮，可随时在**自适应全高展开**与**紧凑模式（最大 `416px`）**之间即时切换。
   - 点击 **`全屏`** 按钮可尝试全屏查看；此外，由于 Antigravity 聊天内嵌框（`<agent-embed>`）外层高度本身存在约 `500px` 的宿主上限，对于预估高度超过 `480px` 的竖版长图，助手还会在卡片下方附带 **`[全高卡片视图]`** 与 **`[Pele Studio]`** 快捷链接，点击即可在右侧面板中以完整窗口高度无裁切浏览。
   - 助手调用 `pele_render_card` 或用户在 CLI 使用 `agy-pele render` / `extract` 时，也可通过 `height`（`"auto"` / `"compact"` / `"680"`）与 `maxHeight` 显式定制初始高度。
6. **快捷操作与导出**：
   - **复制**：一键将图表源码复制到剪贴板。
   - **SVG**：下载当前已注入 Flexoki 样式变量的矢量 `.svg` 文件。
   - **PNG**：将图表高分辨率栅格化为 **2x PNG**（自动匹配当前卡片处于浅色还是暗黑模式）并下载。

## 3. Pele Studio 右侧工作台

**Pele Studio** 是集成在 Antigravity 右侧辅助面板（`AUX_PANE`）中的实时图表 IDE。

### 如何打开

- 在对话中点击助手返回的 `[Pele Studio](sidecar://antigravity-pele/pele_studio/)` 快捷胶囊；或
- 在对话中请助手 *"在 Pele Studio 中打开某个文件"*（内部调用 `pele_open_in_studio`）；或
- 在终端运行独立浏览器版本：`agy-pele preview [目录或文件]`。

### 核心工作区功能

1. **双源聚合导航树**：
   - **当前会话（Conversation）**：自动收录本对话中生成过的全部内联卡片、SVG Artifact 与草稿，按时间同步更新。
   - **当前工作区（Workspace）**：自动扫描当前项目内的 `.md`、`.markdown`、`.mmd`、`.mermaid` 文件，并将 Markdown 文件中含有的每一个 Mermaid 代码块拆分为独立可点选条目（显示所在文件名与起始行号）。
2. **`<1ms` 实时源码编辑器**：
   - 修改左侧编辑器中的代码，右侧 SVG 画布在毫秒级无闪烁更新。
   - 若存在语法错误，底部状态栏会显示来自 Pele 解析器的**精确行/列号与错误摘要**，同时画布保留上一次有效图形不会崩溃闪白。
3. **内置 Scratchpad 草稿模板**：
   - 一键新建 `swimlane`、`agentflow`、`gantt`、`mindmap`、`sequence`、`railroad`、`venn`、`cynefin` 等典型示例，快速验证想法。
4. **哈希防冲突安全回写（`保存回源文件`）**：
   - 选中来自工作区 `.md` 或 `.mmd` 的图表并在 Studio 修改满意后，点击**保存**，后端会执行：
     1. **工作区路径 containment 校验**（含符号链接真实路径校验）。
     2. **SHA-256 内容哈希比对**：若目标代码块自加载后已在外部被你或 Agent 修改，服务端会拒绝覆盖并返回 `HASH_CONFLICT (HTTP 409)` 提示。
     3. **行尾换行符保留（CRLF/LF）+ 同级临时文件原子替换（`fs.renameSync`）**：确保不会破坏原文件其余部分与跨平台换行符格式。
5. **多倍率 PNG 与矢量 SVG 导出**：
   - 支持 **SVG** 及 **1x / 2x / 3x PNG** 一键导出，方便嵌入文档、PPT 或对外汇报。
